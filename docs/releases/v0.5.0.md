# MeoList v0.5.0

- Mark stages while the overall stopwatch keeps running. Completed stages show fixed durations.
- Create activity subprojects and assign stages for the current session. Unplanned stages remain unassigned until selected.
- Open any time record to inspect its stages and subproject time-distribution chart.
- Choose and reorder 3–5 bottom shortcuts. Tasks, Timer and More remain required; More stays last.
- Keep every optional page reachable from More, including Habits and Farm.

Compatibility: Room migrates from v2 to v3 and retains historical records and farm progress.
JSON backup format remains 2, with format 1 import support. New backups preserve subprojects,
active stage plans, stage snapshots and navigation preferences. Restore these backups with
v0.5.0 or later to retain the new fields. CSV continues to export one row per whole time record.

# MeoList v0.5.0

- 秒表持续累计总用时，打点后展示已完成阶段的固定用时。
- 支持活动子项目及仅用于本次计时的阶段归属；预设用尽后的阶段可手动分配。
- 点击计时记录，查看阶段明细和该次记录的子项目占比图。
- 底栏支持选择、排序 3–5 个入口；任务、计时、更多必须保留，更多固定在最右侧。
- 所有可选功能均可从更多进入，包括习惯和农场。

兼容性：Room 数据库由 v2 升级至 v3，保留历史计时记录与农场进度。
JSON 备份格式保持为 2，继续支持格式 1 导入；新备份包含子项目、运行中的阶段方案、
阶段快照及导航配置。请使用 v0.5.0 或更新版本恢复，以保留新增数据。
CSV 继续以整条计时记录为单位导出，每条记录一行。
