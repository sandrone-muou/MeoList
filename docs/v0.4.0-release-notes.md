# MeoList 0.4.0

- More now uses full-width grouped lists with readable descriptions.
- Tasks has a new list/calendar switch. Categories, lists, folders and tags are available from the filter row in the page, and folders can collapse.
- Browse tasks by month or week and add tasks for the selected date. The task calendar shows all visible lists independently of the list filter; switching back restores that filter.
- Add tasks from the selected day's agenda in More → Calendar, with dates, times, priorities, lists, tags and reminders.
- Quick add supports continuous entry, keeps input after save failures, and prevents duplicate submissions while saving. Task and reminder creation is atomic.
- Task titles and metadata wrap to accommodate larger fonts.
- Switching the time picker from typed input to the wheel preserves the hour in 24-hour mode.

Compatibility: Android 8.0+. Room remains at schema version 2; no database migration is required. Backup format 2 and format 1 imports remain supported. Existing tasks, habits, tracked time and farm history are preserved.

# MeoList 0.4.0

- 更多页面改为全宽分组列表，说明文字完整显示。
- 任务页新增列表／日历切换；分类、清单、文件夹与标签统一从正文筛选入口选择，文件夹可展开或收起。
- 支持按月／周查看任务，为选中日期直接新建任务。任务日历独立展示各清单任务，切回列表恢复原筛选。
- 支持从“更多 → 日历”的当天安排中新建任务，可设置日期、时间、优先级、清单、标签和提醒。
- 快捷新建支持连续录入，保存失败保留输入，保存期间防止重复提交；任务与提醒在同一事务中创建。
- 任务标题与辅助信息可换行，适配大字体。
- 修复 24 小时制下时间选择器从输入切回滚轮时小时发生变化的问题。

兼容性：支持 Android 8.0 及以上版本。Room 数据库维持版本 2，无需数据库迁移。继续使用备份格式 2，并支持导入格式 1。已有任务、习惯、计时和农场历史保留。
