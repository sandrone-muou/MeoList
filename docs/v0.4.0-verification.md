# MeoList 0.4.0 verification

Version: `0.4.0`, version code `9`. Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Automated checks

- `./gradlew.bat assembleDebug test lintDebug --console=plain` passed. The app lint report contains 0 errors and 31 warnings.
- `./gradlew.bat test connectedDebugAndroidTest --console=plain` passed on the Pixel 9 Pro emulator (Android 17).
- 203 JVM tests passed, counting debug/JVM results once rather than counting the release variants again.
- 22 instrumented tests passed across app, data, notification and settings.
- `git diff --check` passed.

New coverage includes local-time date grouping, archived/deleted/subtask visibility, completed-task ordering, month-end clamping, leap years, year boundaries and week starts; task/date/tag/reminder creation; Room rollback and retry after reminder-write failure; independent list filters; view/date restoration after activity recreation and tab navigation; and both calendar creation routes with cancellation.

The full instrumented run preceded the final cosmetic change to task checkbox alignment and tag contrast. Build, JVM tests and lint were rerun after that change.

## Device and visual checks

Target viewport: 1216 × 2640 pixels at 480 dpi (approximately 405 dp wide). English and Chinese, light and dark themes, and font scales 1.0 and 1.3 were checked. Screenshots and UI hierarchies are saved locally under `build/screens/small/` with names of the form `<language>-<theme>-<font-scale>-<screen>.png` and `.xml`.

Checked screens: task list, filter sheet and its lower entries, task month/week calendar, More, comprehensive month/week calendar, and full-page task creation with the keyboard open. Fixtures include a long bilingual task title, list, folder and tag. Text wraps, sheet contents remain scrollable, and creation controls remain reachable. Task-only captures at 1.3 were refreshed after the final contrast/alignment change.

Manual entry checks included two consecutive saves in quick add, with the title cleared and other choices retained. A task was also saved from an empty date in the following week of the comprehensive calendar: navigation returned to that date, and a database check confirmed exactly one task with the selected due date, `allDay = true` and no list. QA fixtures were removed after verification and the original device display/language settings were restored.

## Compatibility and delivery

Room stays at version 2. Backup format 2 and format 1 import remain supported; no schema migration or new dependency was introduced. The existing farm and backup test fixtures were updated to match the current field-ledger model and required format-2 fields, with no production changes to those models.
