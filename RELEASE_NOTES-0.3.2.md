# MeoList 0.3.2

The manual record editor now uses a wheel picker that includes every minute from 00 to 59. Switch
to numeric input whenever typing is quicker. The same picker is used by task times and reminders.

The “Every field grows” farm card now has a close button. Its hidden state is remembered on the
device.

Compatibility: the database stays at version 2 and backups remain format 2 with format 1 import
support. Existing records, farm progress and settings continue to load without migration.

# MeoList 0.3.2

手动记录现在使用包含 00 到 59 全部分钟的双列滚轮，也可切换到数字输入精确填写。任务时间和提醒
时间也统一使用新的选择器。

农场的“每块田都会生长”说明卡新增关闭按钮，关闭状态会保存在本机。

兼容性：数据库仍为版本 2，备份仍为格式 2，并继续支持导入格式 1。现有记录、农场进度和设置无需
迁移即可继续使用。
